# Toasty Studio Integration

Purpose: explore Seeker as a mobile client/platform for Toasty Studio.

The existing Toasty architecture remains authoritative. This integration does not rebuild Toasty Studio and does not add crypto functionality merely because Seeker supports it.

The scaffold models how a Seeker client could:

- Join an existing Toasty session.
- Provide camera and microphone permissions.
- Participate in the existing remote recording/session architecture.
- Use shared Seeker identity or wallet capabilities later only where they provide actual value.
